# 🏛️ نظام متابعة حضور وانصراف موظفي المقر
## NOCI Employee Attendance & Biometric Intelligence System

نظام ويب وتطبيق متعدد المنصات (Flutter Multiplatform & Node.js/SQLite) لإدارة ومتابعة وتحليل كشوفات البصمة اليومية لموظفي المقر باللجنة الأولمبية الوطنية العراقية (NOCI).

---

## 🚀 المميزات الرئيسية:
- **تحليل البصمة اليومية الذكي:** معالجة ملفات الإكسل اليومية وتحديد أوقات الدخول والانصراف وحساب التأخير والغياب والمكافآت وتصفية التكرار اللحظي (Double Tap).
- **التشخيص اللوني التفاعلي:**
  - 🟢 **أخضر:** حضور في الوقت (حتى 10:00 صباحاً).
  - 🟡 **أصفر:** تأخير بسيط (10:01 إلى 10:30 صباحاً) أو انصراف مبكر.
  - 🟠 **برتقالي:** تأخير كبير (بعد 10:30 صباحاً).
  - 🔴 **أحمر:** غياب تام بدون عذر.
  - 🔵 **أزرق:** مجاز رسمياً.
  - ⚪ **رمادي:** مستثنى قيادي (VIP).
- **محرك المكافآت والإضافي:** حساب دقائق الحضور المبكر (قبل 09:00 أو 09:30) والدوام الإضافي (بعد 15:00) بنمطين (افتراضي أو يدوي مخصص).
- **استثناء الشخصيات القيادية (VIP):** استثناء الأمين العام، الأمين المالي، المستشارين بنقرة زر.
- **استثناء الأقسام والحالات الخاصة:** عزل المنسبين والمستقيلين والخدمات عن كشوفات الغياب.
- **سجل الحركات الأمني (Audit Logs):** توثيق كل حركة في النظام بالوقت والمستخدم والـ IP.
- **المحادثة الفورية المباشرة (Internal Chat):** محادثة إدارية مدمجة مع تحديث صامت كل 3 ثوانٍ.
- **لوحة السوبر أدمن:** شريط الإعلانات والتعاميم العلوي، وضع الصيانة، إدارة الصلاحيات، وترحيل السنوات (2026 -> 2027).
- **التقارير والتصدير:** كشوفات يومية وشهرية وتصدير منسق إلى Excel.

---

## 🗂️ هيكلية المشروع:
- `app/`: تطبيق Flutter متعدد المنصات (Web, Android, iOS, Windows).
- `backend/`: خادم الـ API وقاعدة البيانات المحلية فائقة السرعة SQLite (Better-SQLite3).
- `toolkit/`: حزمة التشغيل والنشر السريع ونفق Cloudflare (`setup-cloudflare-tunnel.ps1`).
- `خطط/`: التوثيق المعماري، سجل الإنجاز والمشاكل والحلول، ودليل بناء ويندوز وماك.
- `اساس/`: ملفات النماذج وقوائم الموظفين المعتمدة.

---

## 💻 التشغيل السريع:
1. لتشغيل النظام محلياً:
   ```cmd
   .\toolkit\run-local.bat
   ```
2. افتح المتصفح على: `http://localhost:5000`
3. حساب السوبر أدمن الافتراضي:
   - المستخدم: `admin`
   - كلمة المرور: `Admin@123456`
