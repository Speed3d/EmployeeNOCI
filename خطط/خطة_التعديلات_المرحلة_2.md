## 1. أخطاء اكتشفتها في الكود الحالي (تُصلح ضمن التنفيذ)
1. العطل الرسمية وعطلة نهاية الأسبوع كانت تُسجَّل `VIP_EXEMPT` ← حالات مستقلة `HOLIDAY` و`OFF_DAY`.
2. رفع الكشف كان يحفظ مباشرة ← تحليل (معاينة) ثم حفظ (اعتماد).
3. القسم لا يُحفظ وقت التسجيل ← `department_snapshot` داخل كل سجل.
4. البصمات الخام لم تكن تُحفظ ← تُحفظ في `attendance_days.raw_punches` لإعادة التحليل.
5. فلتر البصمة المزدوجة كان يُحسب ولا يُستعمل ← يُستعمل فعلياً.
6. وضع المكافأة (افتراضي/مخصص) كان يتجاهل الاختيار ← يُطبَّق فعلاً. والمكافأة تُحسب من وقت العتبة (09:00 / 15:00).
7. بصمة واحدة بعد الظهر كانت تُحسب «تأخير 5 ساعات» ← تُعامل كبصمة خروج فقط.
8. مفتاح JWT ثابت داخل الكود ← يُولَّد عشوائياً لكل تثبيت ويُحفظ خارج Git.
9. ملف قاعدة البيانات كان مرفوعاً إلى GitHub ← يُزال من التتبع ويُضاف إلى `.gitignore`.

## 2. معمارية القرارات الأساسية
- **مصدر واحد للاستثناءات:** جدول `departments.is_excluded` + `employees.is_exempt` + `employees.status`. كل الشاشات تقرأ منه.
- **الموظف المستبعد (قسم مستبعد / غير نشط / VIP) لا يظهر إطلاقاً** في كشف الحضور ولا الإجازات ولا التقارير.
- **أولوية الحالة اليومية:** عطلة رسمية ← يوم أوف (جدول أسبوعي ← ثابت ← الافتراضي أحد–خميس) ← إجازة ← تحليل البصمة.
- **الأسبوع يبدأ الأحد.** القالب = مجموعة أيام عمل. الربط الأسبوعي يتغلب على الثابت.
- **معاينة ثم اعتماد:** التحليل لا يكتب شيئاً. الحفظ يكتب السجلات و`attendance_days` ويدخل التقارير الشهرية.
- **السجلات المحفوظة لقطة ثابتة.** تغيّر الإجازات/الجداول لاحقاً يظهر عبر «إعادة التحليل من المحفوظ» ثم إعادة الاعتماد.
- **الفلاتر في كشف الحضور** تعمل على الواجهة فوق كامل نتائج اليوم.
- **التصدير:** نقطة عامة `POST /reports/export-excel` تستقبل الأعمدة والصفوف الظاهرة (تحترم الفلاتر) وتعيد ملف xlsx يُنزَّل فعلياً.
