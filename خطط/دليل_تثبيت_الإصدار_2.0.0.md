# دليل تثبيت وتحديث الإصدار 2.0.0

## الملفات الجاهزة
تُبنى الملفات في المجلد `releases/v2.0.0/`، وهو غير مرفوع إلى GitHub بسبب حجمه:

| الملف | الاستخدام |
|---|---|
| `NOCI-Attendance-2.0.0-windows.zip` | تطبيق ويندوز المكتبي (فك الضغط ثم تشغيل `noci_attendance.exe`) |
| `NOCI-Attendance-2.0.0.apk` | تطبيق أندرويد |
| `app/build/web/` | نسخة الويب، ويستضيفها الخادم تلقائياً على `http://localhost:5000` |

لإعادة بنائها:
```bash
cd app && flutter build web --release && flutter build windows --release && flutter build apk --release
```

---

## 1. تحديث الخادم (الجهاز الرئيسي)
1. أوقف النظام بالنقر مرتين على `إيقاف النظام.bat`.
2. **خذ نسخة احتياطية** من المجلد `backend/data` كاملاً.
3. اسحب التحديث، ثم ثبّت المكتبات:
   ```bash
   git pull
   ```
   ```bash
   cd backend && npm install
   ```
4. شغّل النظام بالنقر مرتين على `تشغيل النظام.bat`. عند أول تشغيل:
   - تُرقّى قاعدة البيانات تلقائياً.
   - تنتقل مفاتيح التشفير إلى `backend/.keys/secrets.json`. **انسخ هذا الملف إلى مكان آمن.**
5. للتأكد من سلامة الخادم:
   ```bash
   cd backend && npm test
   ```

### التشغيل التلقائي مع الويندوز
شغّل `toolkit/install-startup-service.bat` مرة واحدة. يعمل الخادم بعدها في الخلفية مع إعادة تشغيل تلقائية عند أي تعطل، ويكتب سجله في `backend/logs/server.log`.

### عند النشر عبر Cloudflare فقط
أضف إلى ملف `backend/.env` السطر التالي، حتى لا يُقبل اتصال غير مشفر من الشبكة المحلية:
```
HOST=127.0.0.1
```

## 2. تطبيق ويندوز المكتبي
1. فك ضغط `NOCI-Attendance-2.0.0-windows.zip` في أي مجلد (مثلاً `C:\NOCI`).
2. شغّل `noci_attendance.exe`، ويمكنك إنشاء اختصار له على سطح المكتب.
3. إذا كان الخادم على جهاز آخر: من شاشة الدخول اختر **"ضبط عنوان الخادم (API)"** وأدخل العنوان، مثل `http://192.168.1.10:5000/api` أو `https://Employee.nociraq.com/api`.

## 3. تطبيق أندرويد
1. انقل ملف `NOCI-Attendance-2.0.0.apk` إلى الهاتف وثبّته (يجب السماح بالتثبيت من مصادر خارجية).
2. من شاشة الدخول اختر **"ضبط عنوان الخادم (API)"** وأدخل عنوان الخادم، لأن العنوان الافتراضي مخصص للمحاكي فقط.
3. ملاحظة: هذه النسخة موقّعة بمفتاح التطوير، وهي صالحة للتوزيع الداخلي فقط. النشر على Google Play يحتاج مفتاح توقيع رسمياً.

## 4. نسخة الويب
بعد تشغيل الخادم افتح `http://localhost:5000`، أو عنوان الدومين عند استخدام Cloudflare.

## أول دخول
- **قاعدة موجودة مسبقاً:** يبقى الأدمن بكلمة مروره الحالية، ويُطلب من الجميع تسجيل الدخول مجدداً.
- **تثبيت جديد:** كلمة مرور الأدمن الأولى عشوائية، وتظهر في نافذة الخادم (أو في `backend/logs/server.log`)، ويُلزم بتغييرها فوراً.
