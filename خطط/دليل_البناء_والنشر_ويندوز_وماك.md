# 💻 دليل البناء والتشغيل والنشر على الحاسبتين (Windows & macOS)
## نظام البصمة والحضور لموظفي المقر — NOCI Attendance

يوثق هذا الدليل طريقة إدارة وتطوير وبناء النظام عبر الحاسبتين المعتمدتين وطرق التحكم بدورة حياة الخادم:

---

## 1. دورة تشغيل وإيقاف النظام على ويندوز (Server Lifecycle Management)

### التشغيل اليومي السريع:
- النقر مرتين على `تشغيل النظام.bat` في المجلد الرئيسي.
- يقوم السكربت بتشغيل الخادم، واستضافة حزمة الويب المبنية، وفتح المتصفح تلقائياً على المنفذ الثابت:
  `http://localhost:5000`

### كيفية إيقاف النظام (بدون إعادة تشغيل الكمبيوتر):
لإيقاف الخادم وتحرير المنفذ 5000 بنسبة 100%:
1. **الخيار 1 (المباشر):** إغلاق نافذة موجه الأوامر (CMD) بالضغط على `X` في زاوية النافذة أو `Ctrl + C`.
2. **الخيار 2 (السكربت السريع):** النقر مرتين على `إيقاف النظام.bat` في المجلد الرئيسي، حيث يقوم بالبحث عن أي عملية على المنفذ 5000 وإنهاءها قسرياً وتحرير المنفذ.
3. **الخيار 3 (سطر الأوامر PowerShell):**
   ```powershell
   Get-NetTCPConnection -LocalPort 5000 -ErrorAction SilentlyContinue | ForEach-Object { Stop-Process -Id $_.OwningProcess -Force }
   ```

### التشغيل عبر بيئة التطوير VS Code (منفذ 5000 الثابت):
تم تهيئة ملف `.vscode/launch.json` لضمان أن تشغيل واجهة فلاتر في بيئة التطوير يستخدم دوماً المنفذ الثابت 5000 عبر الوسيط:
`--web-port 5000`

## 2. الحاسوب الأول: حاسوب ويندوز (Windows Main PC)
* **الدور:** بيئة التطوير والتشغيل الرئيسية واستضافة الخادم ونفق Cloudflare وتصدير نسخ (Web, Android, Windows).
* **المتطلبات المثبتة:**
  - Flutter 3.44.4+ مع Dart 3.12+
  - Node.js 24+
  - Cloudflared (للنفق الخارجي)

### الأوامر المعتمدة على ويندوز:
1. **تشغيل الخادم المحلي (Backend API):**
   ```powershell
   cd "d:\Employee NOCI\backend"
   node src/app.js
   ```
2. **بناء وتصدير نسخة الويب (Web App):**
   ```powershell
   cd "d:\Employee NOCI\app"
   flutter build web --release --base-href "/"
   ```
3. **بناء وتصدير نسخة الأندرويد (Android APK):**
   ```powershell
   cd "d:\Employee NOCI\app"
   flutter build apk --release
   # الناتج: app\build\app\outputs\flutter-apk\app-release.apk
   ```
4. **بناء وتصدير نسخة ويندوز المكتبية (Windows Desktop App):**
   ```powershell
   cd "d:\Employee NOCI\app"
   flutter build windows --release
   ```
5. **تشغيل نفق Cloudflare للربط الخارجي:**
   ```powershell
   cloudflared tunnel run noci-attendance
   ```

## 3. الحاسوب الثاني: حاسوب ماك (macOS Mac Machine)
* **الدور:** بناء وتصدير نسخة الآيفون الرسمية (iOS App / IPA).
* **المتطلبات المثبتة على الماك:**
  - Xcode 15+ أو 16+ مع أدوات Command Line Tools
  - CocoaPods (`sudo gem install cocoapods` أو `brew install cocoapods`)
  - Flutter SDK متطابق مع إصدار الويندوز

### خطوات العمل على الماك خطوة بخطوة:
1. **نقل الكود المصدري:**
   - استنساخ المستودع عبر Git من الرابط المعتمد:
     `https://github.com/Speed3d/EmployeeNOCI.git`
2. **تجهيز مكتبات الـ iOS:**
   ```bash
   cd "Employee NOCI/app"
   flutter pub get
   cd ios
   pod install --repo-update
   cd ..
   ```
3. **التشغيل على محاكي الآيفون (iOS Simulator):**
   ```bash
   flutter run -d iPhone
   ```
4. **بناء حزمة الآيفون للإنتاج (iOS Archive / IPA):**
   ```bash
   flutter build ipa --release
   ```
5. **التوجيه للرابط الخارجي الموحد:**
   - تطبيق الآيفون مبرمج مسبقاً ليتصل مباشرة بالدومين السحابي:
     `https://Employee.nociraq.com/api`
   - لا يحتاج مستخدم الآيفون أن يكون على نفس الشبكة المحلية؛ النفق يربطه فوراً بالخادم الرئيسي أينما كان.
